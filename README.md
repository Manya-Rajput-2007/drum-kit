# 🥁 Drum Kit

An interactive web-based Drum Kit application that allows users to play different drum sounds using keyboard keys or by clicking the drum buttons.

This project was created to practice JavaScript event handling, DOM manipulation, and building interactive web applications.

---

## 📌 About the Project

The Drum Kit is a fun and interactive browser-based musical application.

Each button represents a different drum instrument and produces a corresponding sound when activated. Users can interact with the application either by clicking the buttons or pressing specific keys on their keyboard.

The project demonstrates how HTML, CSS, and JavaScript work together to create an engaging user experience.

## ⚙️ How It Works

### 1. HTML Structure

HTML creates the buttons and layout for each drum instrument.

Each drum button is associated with a specific keyboard key.

### 2. CSS Styling

CSS is used to:

* Design the drum buttons.
* Create visual feedback.
* Add animations.
* Improve the overall appearance of the application.

### 3. JavaScript Functionality

JavaScript handles:

* Click events.
* Keyboard events.
* Audio playback.
* Button animations.

When a user presses a key or clicks a button, JavaScript identifies the corresponding drum sound and plays it.
